# Remote Exhibit — Gate 0 fixtures

Synthetic triangle and 4×4 texture data for a VRChat/Udon feasibility test.
These files contain no avatar, clothing, user data, or executable code.
The G0EX test format is experimental and is not the production VEX format.

Valid fixtures: rgba-quadrants, rgba-gray-srgb, rgba-gray-linear, dxt1-mips, dxt5-alpha-mips.
Intentionally invalid fixtures: truncated, bad-index, nan-position, bad-mip.
Use only with the Gate 0 probe. Do not interpret these fixtures as general-purpose 3D files.

Published v1 bytes must remain unchanged. Use a new version directory for revised data.
